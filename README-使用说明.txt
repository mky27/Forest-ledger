森屿记账 · iPhone 记账网站

【启动】
1. 直接查看：打开 index.html（本地文件形式仅适合临时体验）。
2. 推荐：把这个文件夹上传到支持静态网页的 HTTPS 空间，例如 Netlify Drop / GitHub Pages，获得固定网址。
3. 在 iPhone Safari 打开固定网址 → 分享 → 加入主屏幕。以后像 App 一样使用。

【功能】
· 首页分类快速记支出；新增按钮可切换支出、收入、转账。
· 「我的」：修改现金、银行、电子钱包的初始余额，可新建账户。
· 「固定」：设定名称、金额、分类、日期、扣款账户、起止月份。
· 固定扣款只会记入账本，不会实际从银行扣款。网站打开时会补记到期项目。
· 「预算」：按类别设置每月上限；「明细」：查找和修改记录。
· 「我的」→ 导出 JSON 完整备份，存到 iCloud Drive；可导入恢复。CSV 适合查看流水。

【注意】
所有账本数据保存在当前浏览器或安装后的网页应用本地，没有账户登录与跨设备自动同步。
清理网站数据、删除网页应用、换网址或换设备，可能导致数据遗失；建议定期 JSON 备份。
最好一直用同一浏览器及同一网址。部分 iOS 版本将 Safari 网站与主屏幕网页应用的数据隔离，请选一个入口长期使用。

默认币种：RM / MYR
